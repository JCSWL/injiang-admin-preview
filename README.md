# in疆 Web运营管理端 Demo

这是纯 HTML / CSS / JavaScript 的交互演示，不是生产后台。

打开 `index.html` 即可使用，也可通过 GitHub Pages 在线查看。

- 管理层：数据看板、经营报表、风险提醒。
- 运营：业务资料、审核、订单处理与配置。
- 超管：运营范围加城市、账号及操作日志。

角色切换只用于演示，不是登录认证或安全权限系统。所有业务数据都是虚构样例；修改仅保存在当前页面内存，刷新恢复初始样例。

本地图片、CSV、JSON和ZIP下载可演示。推广码PNG是编号示意图，不是微信小程序码，不能扫码进入小程序。应分金额按示例成交金额和渠道比例计算，仅用于说明对账，不代表利润或真实结算。

不调用数据库、支付、退款、微信消息、短信、上传服务、天气或AI接口。售后、联系和审核结果仅为演示登记；客服答复和通知发送记录为样例。

本仓库只包含管理端必要运行文件，不包含小程序前端、会议、审查文件或内部文档。
